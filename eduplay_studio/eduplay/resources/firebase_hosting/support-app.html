Export/Import HTML
Luồng làm việc chuẩn
  1. Tạo trò chơi trong EduPlay Studio
  2. Export dạng HTML single-file
  3. Trong PowerPoint: mở EduPlay Add-in (nút/tab EduPlay hoặc Add-ins)
  4. Chèn “EduPlay Viewer” lên slide để hiển thị
Lỗi thường gặp
  • Nếu import báo file quá lớn: giảm media hoặc bật compress khi export
  • Nếu HTML có link http/https: export single-file đúng chuẩn (không tải Internet)
  • Nếu viewer không refresh: đóng/mở PowerPoint hoặc chờ vài giây
