PowerPoint Add-in

Cài add-in trực tiếp bằng EduPlay Studio (VSTO Add-in). Nếu Windows hỏi quyền Administrator trong lúc cài, hãy chấp nhận.

Cài đặt nhanh
Cài / Cập nhật Add-in

Dùng chính EduPlay Studio để cài add-in vào PowerPoint. Áp dụng cho Office 2019/2021/2024 và Microsoft 365.

  1. Mở EduPlay Studio → Cài đặt → tab Add-in
  2. Bấm Cài / Sửa chữa Add-in
  3. Đóng hết PowerPoint rồi mở lại
  4. Trong PowerPoint, tìm nút/tab EduPlay (có thể nằm trong tab Add-ins)

Nếu không thấy nút/tab EduPlay: hãy bấm Cài / Sửa chữa Add-in lại 1 lần, đóng/mở lại PowerPoint, và kiểm tra PowerPoint → File → Options → Add-ins → Manage: COM Add-ins → Go… xem EduPlay có đang bị tắt không.

Thông tin chẩn đoán

Nếu gửi lỗi, vui lòng kèm 3 thông tin này.

Office: PowerPoint version (File → Account)
Add-in: URL manifest đã deploy
Mô tả: thao tác + ảnh chụp màn hình + log (nếu có)
