Tạo trò chơi giáo dục và chèn vào PowerPoint

EduPlay Studio là app desktop để giáo viên tạo trò chơi (HTML single-file), đăng lên web và sử dụng trực tiếp trong PowerPoint thông qua Office Add-in.

PowerPoint Add-in (HTTPS)

Dùng manifest đã host trên domain này để triển khai qua Microsoft 365 (Centralized Deployment) hoặc gửi lên AppSource.

Manifest Import (Taskpane) Manifest Viewer (Content)
Sau khi triển khai, bạn có thể mở add-in trong PowerPoint ở Home → Add-ins / My Add-ins.
Chơi game trên web

Mỗi trò chơi sau khi publish sẽ có link dạng 1 path. Truy cập trực tiếp link đó để mở viewer.

https://eduplay-game.web.app/<game_id>
Nếu bạn muốn trang riêng cho library / danh sách game, có thể bổ sung thêm endpoint riêng.
Tài liệu nhanh

1) Cài EduPlay Studio → 2) Export HTML single-file → 3) Import vào PowerPoint (Taskpane Add-in) → 4) Chèn EduPlay Viewer lên slide để hiển thị.
