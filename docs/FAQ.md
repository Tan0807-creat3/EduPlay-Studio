# EduPlay Studio - Frequently Asked Questions (FAQ)

## General Questions

### What is EduPlay Studio?
EduPlay Studio is a desktop application designed for educators to create interactive educational games easily with AI assistance.

### Which operating systems are supported?
Currently, EduPlay Studio is optimized for Windows 10 and 11.

## AI Assistant (Edubot)

### Do I need an API key to use the AI features?
Yes, you need a Groq API key. You can get one from the [Groq Console](https://console.groq.com/).

### Where do I enter my API key?
You can set it as an environment variable (`GROQ_API_KEY`) or enter it in the application's Settings menu.

## Game Templates

### What game templates are available?
- **Quiz Classic**: Standard multiple-choice questions.
- **Quiz Millionaire**: A game show style quiz.
- **Fishing Game**: An interactive game where you catch fish by answering questions.

## Technical Issues

### Tesseract OCR is not working. What should I do?
Ensure you have installed Tesseract OCR and added its path to your system's PATH variable as described in the [Installation Guide](INSTALLATION.md).

### The PowerPoint add-in is not showing up.
Try the "Install / Repair Add-in" button in the Settings menu and restart PowerPoint.
