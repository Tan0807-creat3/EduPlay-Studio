## ✅ Thay đổi 1: HTML Frame là thành phần trong Slide (Không phải overlay)

### Trước đây (v1.0.9):
- ❌ HTML hiện dạng **overlay window** đè lên slide
- ❌ Edit mode và Slide Show đều hiện overlay
- ❌ Không phải là thành phần của slide

### Bây giờ (v1.0.10):
- ✅ **Edit mode**: Hiện shape với text placeholder
  ```
  📄 EduPlay HTML
  
  filename.html
  
  ▶ Press F5 to view
  ```
- ✅ **Slide Show mode**: HTML hiện dạng overlay (chỉ khi trình chiếu)
- ✅ Shape là thành phần thật của slide, có thể:
  - Di chuyển
  - Resize
  - Copy/paste
  - Undo/redo

### Code changes:
```csharp
// TẮT overlay trong edit mode
private void RefreshEditModeOverlays()
{
    CloseSlideShowOverlays();
    // KHÔNG show overlay trong edit mode
    CloseEditModeOverlays();
}

// Shape với text placeholder rõ ràng

shape.Fill.ForeColor.RGB = 0xF0F0F0; // Light gray background
shape.Line.DashStyle = MsoLineDashStyle.msoLineDash; // Dashed border
```

## ✅ Thay đổi 2: Cải thiện Installation

### Vấn đề MSI (ClickOnce):
MSI hiện tại dùng ClickOnce deployment, gây ra:
- ❌ Lock timeout errors
- ❌ Manifest signature errors
- ❌ PowerPoint không mở được

### Giải pháp:
**Script PowerShell** - Copy trực tiếp files:
```powershell
# ppt_vsto_addin\SIMPLE_INSTALL_NO_MSI.ps1
Copy-Item $sourceDir -Destination $destDir -Recurse -Force
```

### Cả 2 cách đều được hỗ trợ:

| Method | Pros | Cons | Khuyến nghị |
|--------|------|------|-------------|
| **MSI** | ✅ Dễ phân phối<br>✅ Double-click install | ⚠️ Có thể lỗi ClickOnce<br>⚠️ Cần uninstall cũ | Thử trước |
| **PowerShell** | ✅ Không bị ClickOnce errors<br>✅ Chắc chắn hoạt động | ⚠️ Cần Run as Admin<br>⚠️ Phức tạp hơn | Nếu MSI lỗi |

## 🎯 Workflow mới:

### 1. Edit Mode (Normal view):
```
User import HTML
  ↓
Shape được tạo với placeholder text
  ↓
"📄 EduPlay HTML
 filename.html
 ▶ Press F5 to view"
  ↓
User có thể di chuyển/resize shape
```

### 2. Slide Show Mode (F5):
```
User nhấn F5
  ↓
SlideShowBegin event fires
  ↓
Add-in đọc HTML từ CustomXMLPart
  ↓
Tạo overlay WebView2 form
  ↓
HTML hiện đè lên shape position
  ↓
User có thể interact với HTML
```

### 3. Kết thúc Slide Show:
```
User nhấn ESC hoặc kết thúc
  ↓
SlideShowEnd event fires
  ↓
Overlay form bị dispose
  ↓
Quay lại edit mode với placeholder
```
