# Roadmap (after 1.0.0)

EduPlay Studio 1.0.0 is the first release. This roadmap describes candidate directions for upcoming versions. Items and order may change.

## 1.1 (planned)

- More question types (sorting, sequencing)
- Undo/redo in editor
- Better export diagnostics (clearer error messages)
- More templates and UI polish

## 1.2 (planned)

- Project backup/export/import improvements
- Better asset management (dedupe, compression options)
- More language coverage for UI + exports

## 2.0 (future)

- Collaboration features (sharing, review workflow)
- More export targets (SCORM/xAPI) if needed by schools
